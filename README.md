
# Smart Task & Project Management System

A web-based task management application built using Python Flask and SQLite.

## Features
- Add, edit and delete tasks
- Task priority management
- Status tracking
- Search and filtering
- Task deadline management
- Overdue alerts
- Task completion dashboard
- Priority distribution chart
- CSV report export

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
- Chart.js

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open in browser:

   http://127.0.0.1:5000

## Database
SQLite database is created automatically when the application starts.
